# PhantomKingdom for Android: Privacy Policy

Last updated: 23 November 2026

PhantomKingdom ("the app") is an open source reimplementation of the
N-Gage game Pocket Kingdom. You play it with the original game files from
your own Pocket Kingdom game card, offline or online through a PhantomLink
server. This policy explains what data the app handles.

## Summary

- The app has no advertising, no analytics and no tracking.
- The developer does not receive any data from the app.
- Online play talks only to the PhantomLink server set in the app
  (188.68.43.183 by default, or an address you enter).

## Data the app sends to the server you choose

Only when you go online (N-Gage Arena in the game's title menu):

| Data | Why |
|---|---|
| Arena user name and password | log in to your account on the server |
| N-Gage ID (a random IMEI-shaped number made by the app on its first start) | the server binds your account to it, as the N-Gage Arena did with a phone's IMEI |
| Kingdom name, game and match data | the online game itself |
| Your Internet (IP) address | needed for any Internet connection |

The server test on the start screen only opens and closes a connection; it
sends nothing. The game protocol is not encrypted, as on the N-Gage. The
server is run by whoever operates it, not by the app's developer; their
own privacy terms apply to it.

## Data stored on your phone

- The game files you import. They are copied into the app's private
  storage, never uploaded, and excluded from backups. "Remove game data"
  deletes them. Files you copy over USB stay where you put them.
- Your saves, settings, the N-Gage ID and the Arena account (server, user
  name, password). These are included in Android's device backup, if you
  have it turned on, so your kingdom survives a phone change.
- A log of app events, kept in memory while the app runs. It is only
  shared if you tap "Share log" yourself.

Uninstalling the app deletes all of it.

## Permissions

- Internet: online play and the server test.
- Vibration: game feedback.
- No storage permission: you pick the files to import with Android's own
  file picker, which grants access to those files only.

## Children

The app is not directed at children under 13.
